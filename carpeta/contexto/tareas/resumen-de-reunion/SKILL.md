# Resumen de reunión

> Skill de base de Trama · estándar .contexto/ v2.0
> Estado: de base. Sirve desde el primer día. Con el primer uso se ajusta a cómo trabaja esta persona.

## Para quién es

Quienes estuvieron en la reunión y quienes tienen que enterarse de lo que se decidió.

## Qué puede producir o mover

Que todos sepan qué se decidió, quién hace qué y para cuándo, sin volver a escuchar la reunión.

## Materiales e instrucciones disponibles

**Datos de cada encargo.** Lo que ya esté en la carpeta o en el pedido se usa. Preguntá solo lo que falte.

- Las notas o la transcripción.
- Quiénes estuvieron y en qué fecha.
- De qué cliente o proyecto era.
- A quién se le manda el resumen.

**Cómo se hace**

1. Empezá por las decisiones: una línea por cada una.
2. Seguí con las tareas: qué, quién y para cuándo. Si no se dijo quién o cuándo, marcalo como pendiente de definir.
3. Anotá lo que quedó abierto y cuándo se retoma.
4. Lo que no está en las notas no se agrega. Si algo no se entiende, se pregunta.
5. Guardalo en la carpeta de ese cliente o proyecto en `trabajo/` y actualizá su `estado.md`.

**Formato.** Entra en una pantalla. Decisiones, tareas y temas abiertos, en ese orden.

**Contexto que consulta.** `con-quien-trabajo.md` y la carpeta del cliente o proyecto en `trabajo/`.
