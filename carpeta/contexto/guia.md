## Capacidades

Skills de base, en `tareas/`. Sirven desde el primer día y se ajustan a la persona con el uso.

- `propuesta`: una propuesta, un presupuesto o una cotización para un cliente.
- `informe`: un informe, un reporte de resultados o el resumen de un período.
- `mail`: escribir o contestar un mail o un mensaje.
- `resumen-de-reunion`: el resumen o la minuta de una reunión, a partir de notas o de una transcripción.
- `presentacion`: una presentación, un deck o un pitch.
- `posteo`: un posteo para LinkedIn, Instagram u otra red.
- `pieza-visual`: una imagen, una placa, un flyer o la gráfica de un posteo.
- `campana`: una campaña o un lanzamiento en varios canales.
- `texto-para-sitio`: los textos de una página web o una landing.
- `video`: un video, un reel o un guion audiovisual.
- `documento`: un instructivo, un manual, un procedimiento o una guía.
